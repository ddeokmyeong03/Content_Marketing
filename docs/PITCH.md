# 서비스 개요 · 타깃 · 판매 자산

> 구현된 기능(참여 엔진 + BGI + 발행 자동화 + 운영 대시보드)을 기준으로 작성한
> 포지셔닝과 판매용 크리에이티브 프롬프트. 전략 근거는 `BUSINESS.md`, 기능 상세는
> `GROWTH_ANALYSIS.md` 참조.

---

## 1. 한 줄 정의

> **당신의 니치에서 "왜 터졌는지"를 학습해, 그 공식으로 다음 콘텐츠를 만드는 SNS 성장 엔진.**

일반 AI 글쓰기 도구가 *글을 뽑아주는 데서 끝난다면*, 이 서비스는
**생성 → 발행 → 측정 → 원인 역설계 → 재현**의 폐루프를 돈다.

## 2. 핵심 개요

| 계층 | 하는 일 |
|------|---------|
| **브랜드 정의** | 니치·청중(고통/욕망/반론)·톤·목표지표를 설정 파일로 고정 |
| **참여 엔진** | 행동심리 레버를 언어에 녹여 훅 N개 생성 → 자기예측 점수로 최적 훅 채택 → 루브릭 자기평가로 미달 시 자동 재생성 |
| **발행 자동화** | 주간 계획 → 캡션 → 검토·승인 → Instagram/Threads 예약 발행 (스케줄러 무인 운영) |
| **BGI 성장 분석** | 팔로워 대비 이상치(브레이크아웃) 탐지 → AI가 왜 떴는지 역설계 → '승리 공식' 축적 → 다음 생성에 재주입 |
| **성장 귀인** | "이 게시물이 신규 팔로워 N명을 데려왔다"를 정량화 |
| **운영 콘솔** | 웹 대시보드에서 키 등록·수집·분석·생성·발행·검토 승인 + 연결 진단 |

## 3. 다른 도구와 결정적으로 다른 점

1. **니치 정조준** — '누구에게나 통하는 글'이 아니라, 정의된 청중의 고통·욕망·반론을 겨냥한 언어
2. **행동심리 내장** — 호기심 갭, 손실 회피, 역발상, 사회적 증거, 정체성 호명 등을 구조적으로 적용
3. **훅 경쟁 방식** — 서로 다른 기법의 훅을 여러 개 만들어 점수로 경쟁시켜 최고를 채택
4. **품질 게이트** — 임계 점수 미만이면 스스로 다시 씀
5. **🔑 브레이크아웃 역설계** — *시중 도구에 거의 없는 기능.* 터진 게시물을 훅 유형·심리 레버·확산 가설·**재현 공식**으로 분해
6. **학습 폐루프** — 그 공식이 다음 기획·캡션에 자동 반영되어, 쓸수록 그 계정에 맞게 날카로워짐
7. **성과 귀인** — 참여율이 아니라 *팔로워 유입*으로 성과를 증명

## 4. 누가 가장 사고 싶은가

### 최우선 타깃 (Beachhead)
**한국의 1인 지식창업가 — 코치 · 컨설턴트 · 온라인 강사**
팔로워 1천~2만, 이미 강의/코칭을 팔고 있으며, 콘텐츠는 계속 올리지만 반응이 정체된 사람.

**왜 이들인가**
- 참여율 → 리드 → 고티켓(수백만 원) 판매로 **매출이 직결** → 가치 기반 가격이 성립
- 전문성은 있으나 **카피·운영 시간이 없다** → 위임(DFY) 의사 높음
- IG·Threads가 핵심 유입 경로 → 플랫폼 일치
- 예산 보유 + 성과 증명이 쉬움(케이스 확보 유리)

### 구매 트리거 (이 순간 지갑이 열린다)
1. **"한 번 터졌는데, 왜 터졌는지 몰라서 다시 못 만든다"** ← 가장 강력한 후킹 포인트
2. 3개월째 팔로워·리드 정체, 매일 올리는데 제자리
3. 카피라이터·소셜 매니저 외주(월 300~500만 원)가 부담
4. 콘텐츠 만드는 데 주 10시간 이상 쓰고 있음

### 확장 타깃 (2단계)
소규모 마케팅 에이전시·프리랜서(다계정 레버리지 → 화이트라벨), 퍼스널 브랜드 빌더

### 초기에 제외
D2C 브랜드(매출 귀인 모호 + 이미지 의존), 대기업(보안·승인 절차)

## 5. 메시지 앵글 (광고·랜딩 공통)

- **핵심 카피**: "터진 게시물이 왜 터졌는지 모르면, 그건 성과가 아니라 우연입니다."
- **약속**: 우연을 공식으로 바꿔 반복 가능하게 만든다
- **가격 앵커**: 소셜 매니저 + 카피라이터 채용 월 300~500만 원 대비
- **금지**: 허위 수치·과장된 보장 (제품 철학과 동일하게 사실 기반)

## 6. 광고 이미지 프롬프트 (1장)

**컨셉**: 평평한 막대들 사이 딱 하나 치솟은 스파이크 → 그 스파이크가 설계도로 분해되는 순간.
"한 번의 우연"이 "재현 가능한 공식"으로 바뀌는 것을 한 장으로.

- CTA: 무료 성장 진단 받기
