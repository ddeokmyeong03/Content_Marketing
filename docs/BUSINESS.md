# 서비스화 전략 (Go-To-Market)

> 이 문서는 **전략 설정**만 담습니다. 구현·개발 항목은 포함하지 않습니다.
> 이 제품을 SaaS 또는 서비스로 판매할 때의 포지셔닝·타깃·가격·채널·로드맵 뼈대입니다.

---

## 1. 핵심 차별점 (왜 이 제품인가)

대부분의 "AI 콘텐츠 생성기"는 범용 캡션을 뽑는 데서 끝납니다. 이 제품의 해자는 **참여율 엔진**입니다:

1. **세부 니치 정조준** — 청중의 고통/욕망/반론을 config로 정의해 언어에 녹임
2. **행동심리 내장** — 호기심 갭·손실 회피·역발상 등 카피 기법을 구조적으로 적용
3. **자기평가·개선 루프** — 생성 후 참여 점수를 매기고 임계 미만이면 자동 재생성
4. **측정 → 학습 순환** — 실제 성과(저장·댓글·공유)를 수집해 다음 기획에 재주입

한 줄 포지셔닝:
> **"그냥 글을 뽑아주는 도구가 아니라, 당신의 니치에서 반응을 만드는 언어를 학습하는 성장 엔진."**

## 2. 타깃 고객 (ICP)

| 세그먼트 | 특징 | 지불 의사 |
|----------|------|-----------|
| **1인 창업가 / 솔로프리너** | 콘텐츠는 필요하나 시간·카피 역량 부족 | 중 — 시간 절약 가치 |
| **퍼스널 브랜드 빌더 / 코치·컨설턴트** | 참여율=리드=매출 직결 | 높음 — ROI 명확 |
| **소규모 에이전시 / 프리랜서 마케터** | 여러 클라이언트를 효율적으로 운영 | 높음 — 다계정 레버리지 |
| **D2C·부티크 브랜드 소셜 담당** | 니치 타깃팅·성과 측정 니즈 | 중~높음 |

**초기 집중(Beachhead)**: 퍼스널 브랜드 빌더 + 코치/컨설턴트 — 참여율이 곧 수익이라 가치 증명이 가장 쉬움.

## 3. 가치 제안 (문제 → 해결)

| 고객의 문제 | 이 제품의 해결 |
|-------------|----------------|
| "매일 뭘 올릴지 막막하다" | 니치 맞춤 주간 계획 자동 생성 |
| "글은 쓰는데 반응이 없다" | 행동심리 기반 훅·CTA로 참여 설계 |
| "뭐가 먹히는지 모르겠다" | 성과 수집 → 상위 각도 학습·재현 |
| "관리할 시간이 없다" | 계획→생성→예약 발행 무인 자동화 |

## 4. 패키징 & 가격 모델 (초안)

### 모델 옵션
- **(권장) SaaS 구독** — 셀프서브, 확장성 최고
- **DFY(Done-For-You) 서비스** — 초기 현금흐름·레퍼런스 확보에 유리
- **하이브리드** — DFY로 시작해 SaaS로 전환 (권장 진입 순서)

### 구독 티어 (예시, 월 기준)
| 티어 | 대상 | 포함 | 가격대(예시) |
|------|------|------|--------------|
| **Starter** | 1인·1계정 | 주간 계획+캡션 생성, 수동 발행, 기본 니치 1개 | $19–29 |
| **Pro** | 퍼스널 브랜드 | 자동 발행 스케줄러, 성과 학습 루프, 알림, 니치 3개 | $59–99 |
| **Agency** | 에이전시·다계정 | 다계정 관리, 팀 검토 워크플로우, 우선 지원 | $199–399 |
| **DFY** | 위임 선호 | 전략 세팅 + 월간 운영 대행 | $500–1,500 + |

> 가격 앵커: "카피라이터/소셜 매니저 1명 외주비 대비 1/5" 프레이밍. 성과(참여율↑) 기반 가치 가격 책정 여지.

### 과금 축(사용량 레버)
- 관리 계정 수 / 월 생성 포스트 수 / 니치(브랜드 프로필) 수 / 최적화 재생성 강도(`min_hook_score`) / 성과 학습 데이터 보존 기간

## 5. 차별화 & 해자 (경쟁 방어)

- **니치 성과 데이터 축적** — 계정별 학습 데이터가 쌓일수록 이탈 비용↑ (데이터 해자)
- **심리 레버 라이브러리** — 지속 확장 가능한 IP 자산
- **측정-학습 폐루프** — 단순 생성기와 근본적으로 다른 "성장" 내러티브
- **화이트라벨** — 에이전시 대상 리셀러 옵션으로 확장

---

## 6. 판매 채널 (GTM)

1. **콘텐츠 셀프 도그푸딩** — 이 엔진으로 만든 콘텐츠로 직접 성장 = 살아있는 데모 (가장 강력)
2. **케이스 스터디** — 베타 고객의 "참여율 N배" 성과를 증거로
3. **커뮤니티/뉴스레터** — 1인 창업·마케팅 커뮤니티 침투
4. **에이전시 파트너십** — 화이트라벨 리셀
5. **프로덕트 헌트/인디 채널** — 초기 얼리어답터 확보

---

## 7. 지표 (North Star & KPI)

- **North Star**: 고객 계정의 **평균 참여율 개선폭**(도입 전후) — 제품 가치와 직결
- 활성화: 첫 주간 계획 생성 완료율
- 리텐션: 월 재생성/발행 지속률, 학습 루프 사용률
- 수익: MRR, ARPU, 티어 업그레이드율
- 이탈 선행지표: 성과 데이터 축적량(낮을수록 이탈 위험)

## 8. 단계별 로드맵 (비즈니스 관점, 개발 아님)

| 단계 | 목표 | 활동 |
|------|------|------|
| **0. 검증** | PMF 신호 | 5–10명 베타에 무료/DFY 제공, 참여율 개선 케이스 확보 |
| **1. 수익화** | 첫 유료 고객 | Pro 티어 + DFY 병행, 케이스 스터디 발행 |
| **2. 셀프서브** | 확장 | SaaS 온보딩 정비, Starter 티어 공개 |
| **3. 레버리지** | 규모화 | Agency/화이트라벨, 파트너 채널 |
