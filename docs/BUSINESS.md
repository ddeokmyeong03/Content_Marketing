# 서비스화 전략 (Go-To-Market)

> 이 문서는 **전략 설정**만 담습니다. 구현·개발 항목은 포함하지 않습니다.
> 이 제품을 SaaS 또는 서비스로 판매할 때의 포지셔닝·타깃·가격·채널·로드맵 뼈대입니다.

---

## 1. 핵심 차별점 (왜 이 제품인가)

대부분의 "AI 콘텐츠 생성기"는 범용 캡션을 뽑는 데서 끝납니다. 이 제품의 해자는 **참여율 엔진**입니다:

1. **세부 니치 정조준** — 청중의 고통/욕망/반론을 config로 정의해 언어에 녹임
2. **행동심리 내장** — 호기심 갭·손실 회피·역발상 등 카피 기법을 구조적으로 적용
3. **자기평가·개선 루프** — 생성 후 참여 점수를 매기고 임계 미만이면 자동 재생성
4. **측정 → 학습 순환** — 실제 성과(저장·댓글·공유)를 수집해 다음 기획에 재주입

한 줄 포지셔닝:
> **"그냥 글을 뽑아주는 도구가 아니라, 당신의 니치에서 반응을 만드는 언어를 학습하는 성장 엔진."**

## 2. 타깃 고객 (ICP)

| 세그먼트 | 특징 | 지불 의사 |
|----------|------|-----------|
| **1인 창업가 / 솔로프리너** | 콘텐츠는 필요하나 시간·카피 역량 부족 | 중 — 시간 절약 가치 |
| **퍼스널 브랜드 빌더 / 코치·컨설턴트** | 참여율=리드=매출 직결 | 높음 — ROI 명확 |
| **소규모 에이전시 / 프리랜서 마케터** | 여러 클라이언트를 효율적으로 운영 | 높음 — 다계정 레버리지 |
| **D2C·부티크 브랜드 소셜 담당** | 니치 타깃팅·성과 측정 니즈 | 중~높음 |

**초기 집중(Beachhead) — 확정**: **한국 1인 지식창업가(코치·컨설턴트·온라인 강사)**. 참여율→리드→고티켓 매출이 직결돼 가치 기반 가격이 성립하고 DFY 위임 의사가 높음. 상세 근거·실행은 §11 참조.

### 모델 옵션
- **(확정 진입) DFY(Done-For-You) 서비스** — 초기 현금흐름·레퍼런스·학습 데이터 확보
- **SaaS 구독** — 셀프서브, 확장성 (2단계 전환 대상)
- **하이브리드** — DFY로 시작해 SaaS로 전환 (채택 경로)

### 구독 티어 (예시, 월 기준)
| 티어 | 대상 | 포함 | 가격대(예시) |
|------|------|------|--------------|
| **Starter** | 1인·1계정 | 주간 계획+캡션 생성, 수동 발행, 기본 니치 1개 | $19–29 |
| **Pro** | 퍼스널 브랜드 | 자동 발행 스케줄러, 성과 학습 루프, 알림, 니치 3개 | $59–99 |
| **Agency** | 에이전시·다계정 | 다계정 관리, 팀 검토 워크플로우, 우선 지원 | $199–399 |
| **DFY** | 위임 선호 | 전략 세팅 + 월간 운영 대행 | $500–1,500 + |

> 가격 앵커: "카피라이터/소셜 매니저 1명 외주비 대비 1/5" 프레이밍. 성과(참여율↑) 기반 가치 가격 책정 여지.

### 과금 축(사용량 레버)
- 관리 계정 수 / 월 생성 포스트 수 / 니치(브랜드 프로필) 수 / 최적화 재생성 강도(`min_hook_score`) / 성과 학습 데이터 보존 기간

## 11. 확정 전략 실행안 (DFY · 가치기반 · IG+Threads)

### 11-1. Beachhead 선정 — 한국 1인 지식창업가 (코치·컨설턴트·온라인 강사)

**왜 이 군인가 (선정 근거)**
- **가치-매출 직결**: 팔로워 → 리드 → 고티켓 프로그램(코칭·강의) 판매. 참여율 상승이 매출로 곧장 이어져 **가치 기반 가격**이 성립.
- **DFY 적합**: 본인은 전문성엔 강하나 카피·콘텐츠 운영엔 시간·역량 부족 → 위임 의사 높음.
- **채널 일치**: IG·Threads가 이들의 핵심 오가닉 유입 경로.
- **지불 능력**: 고티켓 비즈니스라 월 수십~수백만 원 마케팅 예산 보유.
- **증명 용이**: 참여율·리드 개선을 케이스로 만들기 쉬움(레퍼런스 확보).

**탈락 후보(초기 제외 사유)**
- D2C 브랜드: 매출-참여 귀인 모호 + 이미지 의존(현재 IG 이미지 자동화 미구현)으로 적합도↓
- 에이전시: 고객이 아니라 **후기 확장용 화이트라벨 채널** — 2단계로 미룸
- 일반 퍼스널 브랜드: 범위가 넓어 메시지 뾰족함↓

**세부 타깃(초기 1개로 더 좁힘)**: "이미 팔로워 1천~2만, 온라인 강의/코칭을 파는데 콘텐츠 반응이 정체된 1인 지식창업가."

### 11-2. DFY 서비스 구성 (월 단위 제공물)
- **온보딩**: 니치·청중(pains/desires/objections)·심리 레버·목표 지표를 `brand/config.yaml`로 세팅 (고객 인터뷰 기반)
- **주간**: IG+Threads 주간 콘텐츠 계획 + 캡션 생성·검수 → 승인 → 예약 발행
- **이미지 처리(현 단계)**: IG 이미지는 **운영자가 고객 브랜드 자산/디자인 카드로 수급해 `image_urls` 주입** (엔진의 이미지 자동생성 전이라도 IG 발행 가능) — Threads는 텍스트로 즉시 운영
- **월간**: `insights sync`→`top`으로 성과 리포트 + 참여율 개선폭 보고 + 전략 콜 1회
- **지속 최적화**: 성과 학습 루프로 config 튜닝 (먹힌 각도 강화)

### 11-3. 가치 기반 가격 (Value-based)
**원리**: "카피라이터 외주비"가 아니라 **고객이 얻는 가치**(참여율↑ → 리드↑ → 고티켓 매출)를 기준으로 가격을 앵커.

**가격 구조 (3요소)**
1. **셋업 피(1회)**: 전략·니치·엔진 세팅 — ₩1,000,000–2,000,000
2. **월 리테이너**: 운영·생성·발행·리포트 — ₩1,500,000–3,500,000/월 (제공 계정·볼륨·플랫폼 범위에 따라)
3. **(선택) 성과 보너스**: 참여율/리드 개선 목표 초과 시 성과 연동 — 가치 공유 프레이밍

**가치 앵커링 스크립트**
- "소셜 매니저+카피라이터를 채용하면 월 300–500만 원. DFY는 그 이하로 **성과까지 학습**합니다."
- "고티켓 프로그램 1건이 수백만 원이면, 참여율 상승으로 월 리드 몇 건만 늘어도 리테이너를 회수합니다."

**패키지(초안)**
| 패키지 | 대상 | 범위 | 가격(예시) |
|--------|------|------|-----------|
| **Launch** | 첫 도입 | 1계정, Threads 중심 + IG 텍스트카드, 월간 리포트 | 셋업 ₩1M + ₩1.5M/월 |
| **Growth** | 성장 집중 | IG+Threads 풀, 성과 학습 튜닝, 격주 전략 콜 | 셋업 ₩1.5M + ₩2.5M/월 |
| **Authority** | 고티켓 스케일 | 풀 운영 + 성과 보너스 + 우선 대응 | 셋업 ₩2M + ₩3.5M/월 + 성과 연동 |

### 11-4. DFY 운영 방식 (도구 활용, 개발 아님)
- 고객별 격리: 고객마다 별도 `brand/config.yaml` + `DATA_DIR`로 운영(계정/데이터 분리)
- 운영 사이클: `plan generate --captions` → `queue show`로 검수 → 승인 → `serve run`(또는 `post now`) → 월말 `insights sync`/`top`으로 리포트
- 표준 운영 문서(SOP)로 재현성 확보 → 이후 인력/에이전시 레버리지 준비

### 11-5. 세일즈 모션 (DFY)
1. **도그푸딩 데모**: 우리 자체 계정을 이 엔진으로 성장시켜 살아있는 증거로 제시
2. **파일럿 오퍼**: Beachhead 3–5명에 1개월 파일럿(할인/성과조건)으로 케이스 확보
3. **케이스 스터디**: "참여율 N배 / 리드 M건" 결과를 자산화
4. **아웃바운드**: 정체된 지식창업가 DM/이메일 — 그들의 최근 게시물 훅을 리라이트해 무료 샘플로 후킹
5. **추천/파트너**: 만족 고객 → 추천, 이후 에이전시 화이트라벨로 확장

### 11-6. 90일 실행 플랜
| 기간 | 목표 | 핵심 활동 |
|------|------|-----------|
| **0–30일** | 파일럿 확보·첫 성과 | Beachhead 5명 파일럿 온보딩, config 세팅, 첫 주간 발행 |
| **31–60일** | 유료 전환·증거 | 케이스 스터디 2건, 첫 유료 2–3건, 가치 가격 검증 |
| **61–90일** | 표준화·확장 | 유료 3–5건, SOP 정립, 레퍼런스 기반 아웃바운드 본격화 |

**성공 기준(90일)**: 유료 고객 3–5명, 평균 참여율 개선 케이스 2건 이상, 반복 가능한 운영 SOP 완성.

### 11-7. 다음에 정할 것 (실행 세부)

- 아웃바운드 채널·스크립트 A/B
- IG 이미지 자동화(엔진 확장) 도입 시점 — DFY 마진·확장성 개선 레버
